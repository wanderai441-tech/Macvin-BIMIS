
# MACVIN HARDWARE BUSINESS INTEGRATED MANAGEMENT INFORMATION SYSTEM (BIMIS)

## 1. Project Description

The Business Integrated Management Information System (BIMIS) is a computer-based information management system developed for Macvin Hardware & Building Supplies Ltd.

The system is designed to improve the management of business information by integrating major organisational activities into one centralised system.

## 2. Main Objectives

- Improve sales recording and receipt generation.
- Monitor products and stock levels.
- Manage suppliers and purchase requests.
- Record and monitor business expenses.
- Manage employee information and user accounts.
- Generate management and operational reports.
- Improve information sharing between departments.

## 3. System Modules

- Management Overview
- Sales Management
- Inventory Management
- Procurement Management
- Finance Management
- Human Resource Management
- Reports
- User Management

## 4. Technologies Used

- Frontend: HTML, CSS and JavaScript
- Backend: PHP
- Database: MySQL / MariaDB
- Web Server: Apache
- Development Environment: XAMPP

## 5. Database

The system uses a centralised database named `macvin_bimis`.

The database structure is provided in:

`macvin_bimis_structure.sql`

## 6. Installation Requirements

- XAMPP
- PHP
- Apache
- MySQL or MariaDB
- A modern web browser

## 7. Installation Instructions

1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into `C:\xampp\htdocs\`.
4. Open phpMyAdmin.
5. Create a database named `macvin_bimis`.
6. Import `macvin_bimis_structure.sql`.
7. Configure the database connection in `db_connect.php`.
8. Open the application at:

`http://localhost/macvin_bimis/`

9. Create or import the required user accounts before logging in.

## 8. Project Structure

The project contains PHP files for authentication, dashboard access, sales, inventory, procurement, finance, human resources, reports and user management.

## 9. Important Note

The HTML prototype and the PHP/MySQL implementation represent different stages of the system development process.
